Janet in a web page

The Janet runtime compiled to WebAssembly, running in this page. Each run evaluates the text as one line of the janet REPL, in an environment kept between runs. There is no file system, standard input is empty, and os/sleep returns at once.

A browser will not load the WebAssembly from a file:// page. Serve this directory instead, for example with python3 -m http.server run inside it, and open http://localhost:8000/.

Ctrl+Enter or Cmd+Enter also runs.
